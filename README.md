# Unbound

FastAPI backend (`backend/`) + React/Vite frontend (`frontend/`), with Postgres, RustFS (S3) and
Redis in Docker. Details: [backend/README.md](backend/README.md), [frontend/README.md](frontend/README.md).

## Requirements

- Docker Desktop (or Docker Engine + Compose v2)
- Node.js 22+ (`nvm use` reads `.nvmrc`), only needed to run the frontend outside Docker

## Setup

```bash
npm run setup     # creates .env from .env.example, generates JWT_SECRET, installs frontend deps
```

Then fill in `.env`:

| Variable | Needed for |
| --- | --- |
| `GOOGLE_CLIENT_ID` | Sign-in. OAuth "Web application" client, authorised origin `http://localhost:5173` |
| `GEMINI_API_KEY` or `ANTHROPIC_API_KEY` | Chat and document analysis (the rest works without) |
| `JWT_SECRET` | Generated by setup |

`.env` is the only env file you edit: compose passes it to the backend and frontend containers, and
`frontend/vite.config.ts` reads `GOOGLE_CLIENT_ID` from it when running locally.

## Run

Pick one:

```bash
npm run docker:up   # everything in Docker, frontend with hot reload
npm run dev         # services + API in Docker, frontend locally (faster HMR)
```

| Service | URL |
| --- | --- |
| App | http://localhost:5173 |
| API / docs | http://localhost:8000 · http://localhost:8000/docs |
| RustFS console | http://localhost:9001 (`minioadmin` / `minioadmin`) |
| Postgres | `localhost:5432`, `unbound_user` / `unbound_password`, db `unbound_db` |

The app must be on port 5173 (the origin the API allows), so don't run both modes at once.
After changing `.env`, run `npm run docker:up` again to recreate the containers.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run setup` | Create `.env`, install frontend deps |
| `npm run dev` | Backend stack in Docker + local Vite dev server |
| `npm run docker:up` / `docker:down` | Start / stop everything |
| `npm run docker:reset` | Stop and **delete** the database and storage volumes |
| `npm run docker:logs` | Follow backend and frontend logs |
| `npm test` | Backend tests (pytest, in the running backend container) |
| `npm run lint` / `npm run build` | Frontend lint / production build |
| `npm run check` | Lint, build and test |
| `npm run guidelines:import` | Load `backend/data/guidelines/` into the database |
| `npm run models:list` | Gemini models your key can use |

## Production frontend image

```bash
docker build --target prod -t unbound-frontend \
  --build-arg VITE_API_URL=https://api.example.com \
  --build-arg VITE_GOOGLE_CLIENT_ID=... frontend/
```

Serves the built app with nginx on port 80. `VITE_*` values are baked in at build time.
